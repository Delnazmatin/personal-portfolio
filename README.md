# 💻 Personal Portfolio

A responsive personal portfolio website built with **Next.js, React, and TypeScript** to showcase my skills, projects, and experience as a Front-End Developer.

The portfolio includes an introduction, technical skills, selected projects, and contact information, with a clean and responsive design across different screen sizes.

## ✨ Features

- 👩‍💻 Personal introduction and Front-End Developer profile
- 🛠️ Technical skills and technologies
- 📂 Projects showcase
- 📄 Resume download
- 📧 Contact section
- 🔗 GitHub and LinkedIn links
- 📱 Responsive design for mobile, tablet, and desktop
- ⚡ Fast and modern Next.js application

## 🛠️ Built With

- **Next.js**
- **React**
- **TypeScript**
- **React Icons**
- **CSS**
- **ESLint**
- **Prettier**

## 📂 Featured Projects

### 🌍 Langora

A language learning web application built with Next.js and TypeScript.

**Technologies:** Next.js, React, TypeScript, React Hook Form, Zod, CSS

### 🍽️ Menulo

A responsive restaurant menu application with category filtering, search, quantity controls, and cart functionality.

**Technologies:** React, Context API, CSS

### 📊 Admin Panel

A responsive admin dashboard featuring authentication, product management, categories, pricing, tables, and filtering.

**Technologies:** React, React Router, CSS

### 💱 Currency Converter

A currency converter application that allows users to convert between USD and IRR using a user-defined exchange rate.

**Technologies:** React, TypeScript, Tailwind CSS

### 🌤️ Weather App

A weather application that uses a weather API and geocoding to display weather information based on the selected location.

**Technologies:** React, TypeScript, Tailwind CSS, API

### 🐶 PawGallery

A dog breed gallery with breed search, pagination, and responsive card layouts.

**Technologies:** React, TypeScript, Vite, CSS, TheDogAPI
